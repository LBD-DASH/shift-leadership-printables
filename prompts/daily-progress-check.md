# Daily progress check: Shift & Leadership Printables (Canva templates)

## Inputs
Use the repo's `README.md` (the plan, money model, 30-day plan and success/kill criteria), the most recent files in `logs/` (newest first) and anything in `from-cto-new/`. If you're pasting this prompt into a chat assistant, paste or attach those files below it. If no logs are supplied, treat today as Day 1 of the 30-day plan.

## Task
1. Work out which day of the 30-day plan we're on, using the first log date as Day 1.
2. Compare what the plan says should be done by now with what the logs show was actually done.
3. List what's done, behind or blocked, and name the single biggest blocker.
4. Count listings live on Etsy and Gumroad, products in progress, and bundles, and compare with the 25–30 listings target for day 30.
5. Check the success/kill criteria in the README. Say whether any threshold has been hit or is at risk.
6. Give today's top 3 actions, most important first.

## Output
Reply with a single markdown section that starts with the heading `## Daily progress check`. It gets appended to `logs/YYYY-MM-DD.md` (today's date), either by the daily workflow or by Kevin pasting it in.

Rules:
- Don't make up numbers. If a metric isn't in the logs, write "unknown" and say who needs to supply it.
- Keep it short and specific. Kevin should be able to act on it in under 5 minutes.
- Mark anything that needs Kevin personally (accounts, KYC, payments, approvals, reviews) with **[KEVIN]**.
