## Fonts (Google Fonts link in <head>)
- Playfair Display 400–700: all h1–h6 (weight 600), `.font-serif`, italic pull-quotes
- Source Sans 3 300–700: body / html default, `.font-sans`
- Inter 300–700 is loaded too, but the CSS never uses it
- Small labels: uppercase, letter-spaced (tracking 0.3em), in gold or teal
