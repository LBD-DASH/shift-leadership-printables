# Printability critique — One-on-One Meeting Template layout (2026-09-28)

Reviewing the Page 1 / Page 2 layout brief in `logs/2026-09-28.md` for print usability and what a real first-time manager needs. Five specific fixes before this goes into Canva.

1. **Add a one-word "why" line under each 1–5 scale in Box B.** A bare circled number for Workload / Energy / Clarity tells the manager *that* something is off but not *what*. Add a short line under each scale ("In a word, why?") so a "2" on Energy is something the manager can actually act on, not just a number to note and forget.

2. **Add a "Follow-up from last 1:1" prompt at the top of Box A.** As drafted, Page 1 is a stand-alone form with no link back to what was promised last time — continuity only lives on Page 2's tracker, one page removed. A first-time manager needs to close the loop on old actions before opening a new agenda, or Box F's actions quietly die between meetings.

3. **Add a "Next 1:1 date" field next to the sign-off line on Page 1**, not just on Page 2's tracker. The single most common reason recurring 1:1s stop happening is that the room breaks up without a locked date for the next one. This belongs where both people are already signing, not inferred later from the tracker.

4. **Give Box F (Actions) 5–6 rows instead of 4.** A 1:1 that surfaces a growth action (Box E), feedback both ways (Box D) and anything raised in "what's hard right now" (Box C) will regularly need more than 4 actions. Four rows forces the manager to compress separate actions onto one line or drop one, undermining the "clear actions with owners and dates" promise in the listing copy.

5. **Write the row-height budget into the brief before building in Canva.** The brief lists fields (3+3 write-lines, 2 rating scales, 3+3 two-column lines, 2 feedback rows, 2 growth lines, 4–6 action rows, sign-off) but no mm-per-row budget against the stated ≥8mm handwriting line rule and 12mm margins. Usable height on A4 is roughly 273mm; a rough tally of the current fields is tight but workable — confirm the numbers on paper first so the Canva layout doesn't get built oversized and need a redesign after export.
